# Arabic Language Website

This repository contains a simple website about the Arabic language.

## Pages

- `index.md` — homepage with an introduction, facts, and useful phrases
- `contact.md` — contact page for questions and feedback

## About the site

Arabic is one of the most widely spoken languages in the world and is used across the Middle East and North Africa. This site presents basic information for learners and visitors.

## Useful phrases

- Marhaba مرحبا — Hello
- Assalam Alaykum السلام عليكم — Peace be upon you
- Shukran شكراً — Thank you
- Min fadlak من فضلك — Please

Feel free to explore the pages and use the contact page to send feedback.
